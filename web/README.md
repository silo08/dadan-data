# 打单工具 · WEB（浏览器版）

> 把微信小程序「打单小程序」的最新功能搬进浏览器，**与小程序共享同一份数据源**。
> 位置：`打单小程序\web\`，双击 `web\index.html`（或本机起个静态服务）即可用。

## 界面（桌面三栏分段工作台）
- **主界面 = 左·中·右 三栏**（永远保持 3 列区可分配，铺满整屏）：
  - **左栏 · 房间选择台**：补差价 1~9 + 直播间 1~3 列表，点哪个就把房间装进中栏；底部「清空 / 我的」。
  - **中栏 · 房间条 + 编辑器**：顶部房间条（`📋补差价1~9` `📺直播间1~3` `🧮报价成本表` `🔗电商链接总表`），把房间装进中栏。
  - **右栏 · 房间条 + 编辑器**：顶部同样有房间条，把另一个房间/功能装进右栏（可并列对比）。
  - 中、右**互斥**——同一房间不能同时开在中、右，被占用的按钮变灰。
- **电商链接总表**：点击 `window.open` 新开浏览器窗口打开 `https://www.kdocs.cn/l/cbDoagWTC3wF`。
- **补差价（参考 WPS）**：
  - 原配表 = `配件|型号|数量`；改配表 = `配件|型号|数量|补差价`，数量/补差价表头右对齐。
  - 改配分类按钮是**统一等宽、横向单行**的 `.cbtn`（品类 + ➜，按最宽"其他1"定宽），科技感 MINIMAL；卡片标题有「⬇ 全部填入改配」。
  - 快速填入区压缩；总价卡是**固定底部栏**（`.pane` 正文区独立滚动、汇总卡固定），不下滑即可见总价。
- 左↔中 / 中↔右 均可拖宽（默认对半分、精确跟手、记忆比例）；窄屏（<960px）自动上下堆叠。
- 配置名输入框可粘贴/手输、回车或点建议即填入原配（选择器已修索引错位）；报价成本表搜索框常驻不重建。
- 顶部紫渐变横向导航；白卡片 + 圆角 + 大间距；窄屏自动降级为上下堆叠。
- 弹层/选择器为居中对话框。

## 为什么有网页版
- 小程序依赖微信开发者工具 / 真机；网页版**手机 & 电脑浏览器都能直接用**，无需装微信工具。
- 数据链路两条：
  - 小程序：`WPS表 → rebuild → engine\data.js`（内置兜底）+ 云函数 `fetchRemote(dataUrl)` 在线覆盖（A源）。
  - 网页版：`web/` 已**自包含**（`web/engine/`、`web/images/`、`web/fonts/` 都打进 `web/` 内），`<script>` 直接引 `engine/engine.js` + `engine/data.js`（**引擎零改动**）+ `fetch(https://silo08.github.io/dadan-data/data.json)` 在线覆盖。
- **串连机制**：改价/加配置 → 数据编辑器 `data-editor.html` → 「保存并同步到官网」→ `data.json` 更新 → **小程序「验证同步」与网页版「刷新/重开」都能拉到**。两端永远同一份数据。引擎改动（`engine.js`）浏览器自动生效。

## 功能对齐全
- **工作台**（首页）：9 张补差价表 + 3 张直播间表格子，右下角实时总价角标，一键清空全部房间，版本/数据源状态。
- **补差价**：店铺/链接+配置名(两行式，可粘贴筛选)/固态/显卡 联动；原配+改配两段；点型号弹「单搜索框+按类目过滤+可手动输入」底部选择器；点数量/补差价/券前总价弹编辑框；快捷「添加」内存+1 /「改配」内存/固态替换；撤销+恢复；生成紫渐变报价单长图；保存游戏帧数图。工作状态按表单名存**本机 localStorage**（跨刷新保留）。
- **直播间**：店铺/配置/固态/显卡；利润 0/4/6%、平台 0/0.6/2%、运费（内部按机箱大小分档，不显示）；总价可手动改；撤销/恢复；报价单长图；帧数图。工作状态存本机。
- **报价成本表**：三大件/散热/主板/显卡/电源/机箱 六分类 tab + 搜索防抖 + 未税/含税/展示/零售四价 + 拼音排序 + 过滤垃圾行。
- **我的**：设置业务员昵称；显示数据源/版本；跳数据编辑器；一键清空所有房间。
- **噜噜（跳舞水豚）**：10 个雪碧图按天轮播 + 本机 L1-10 切换 + 「下一个全局+1」 + 清除预览 + 拖动定位 + 透明度/大小滑块。

## 使用
1. 双击 `web\index.html`（Chrome / Edge）。
2. 或本机起服务：`python -m http.server 8000` 后访问 `http://localhost:8000/web/`（推荐，弹层/图片路径更稳）。

    ├── store.js        本机持久化 + 事件中心（工作台角标实时刷新）
    ├── ui.js           弹层/toast/弹输入/转义/下载
    ├── picker.js       底部选择器（单搜索框 + 类目过滤 + 手动输入）

## 分工边界
- **计算/数据**：自包含在 `web/engine/`（浏览器直接引用，与小程序共用同一份引擎/数据源）。
- **UI/交互逻辑**：网页版 `js/page-*.js`。小程序新功能若改的是引擎/数据 → 网页自动生效；若改的是页面交互 → 需要把 `pages/xx/xx.js` 的新增逻辑同步到对应 `web/js/page-xx.js`（二者已按页面一一对应，好迁移）。
- **多用户/身份**：网页版为「人人可用 + 本机 localStorage 各自存」，无微信登录，不做管理员白名单；数据发布走数据编辑器 + GitHub。

## 🌏 部署到国内（腾讯云 COS）
- 默认数据走 GitHub `silo08.github.io`（国内慢/可能被墙）；噜噜雪碧图已改为 `web/images/` 本文件夹（离线可用）。要让 WEB 国内顺畅访问 → 部署到 **腾讯云 COS**：
  - `build\deploy_cos.py` 会把整个 `web/`（自包含）+ `data.json` 上传到 COS，并生成**部署版 `web/js/config.js`**（`dataUrl` 指向 COS 的 data.json），使网页走国内数据源。噜噜雪碧图用 `web/images/` 本文件夹（已随 web/ 上传）。
  - 本地 `web/js/config.js` 默认留空 = 本地双击/未部署也能用（读自包含 engine/data.js + 拉 GitHub，失败回退内置）。
- 详细步骤 / 密钥 / CDN / 备案说明见 `WEB部署到腾讯云COS.md`。
- ⚠️ `build/cos_config.json`（含密钥）已加进 `.gitignore`，**别提交**。

## ✂️ 发给别人（单文件夹版）
- **整个 `web\` 文件夹拷走即可**（自包含，含 engine/、images/、fonts/），对方双击 `web\index.html` 就能用。
- ⚠️ 离线/本地用 = **数据快照**（读取打包时内置的 `engine\data.js`）；联网且能连 GitHub 才会拉到最新 `data.json`。国内要稳定收到最新数据 → 用上面的 COS 部署（发网址）。
